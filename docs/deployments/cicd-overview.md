# CI/CD Overview

<span className="badge--intermediate">📚 Intermediate</span>

Learn to set up CI/CD pipelines for AKS deployments. Explore GitHub Actions, Azure DevOps, and Jenkins integration for automated build, test, and deployment workflows.

## Key Concepts

- **GitHub Actions**: GitHub-native workflow automation
- **Azure DevOps Pipelines**: Enterprise CI/CD platform
- **Jenkins Integration**: Traditional CI/CD server with AKS
- **Container Registry**: ACR for image storage and management
- **Image Scanning**: Security scanning during build
- **Deployment Automation**: Automated rollout to AKS
- **Pipeline Stages**: Build, test, deploy, and verify
- **Authentication**: Secure credential management
