# GitOps

<span className="badge--intermediate">📚 Intermediate</span> [<span className="badge--new">🆕 New</span>]

Master GitOps principles and tools for AKS. Learn to use Flux v2 for declarative cluster management and explore the new Argo CD extension for Azure Arc-enabled clusters.

## Key Concepts

- **GitOps Principles**: Git as single source of truth
- **Flux v2**: CNCF project for GitOps on Kubernetes
- **Argo CD Extension**: New managed Argo CD solution for AKS
- **Declarative Configuration**: Infrastructure as code
- **Automated Reconciliation**: Cluster state matches Git
- **Pull-based Deployment**: Controller watches Git repository
- **Multi-cluster Management**: Unified configuration across clusters
- **Policy Enforcement**: Automated policy compliance
