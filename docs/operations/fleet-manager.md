# Fleet Manager

<span className="badge--advanced">🚀 Advanced</span>

Learn to manage multiple AKS clusters as a fleet. Use Azure Kubernetes Fleet Manager for centralized cluster management, update orchestration, and multi-cluster workload placement.

## Key Concepts

- **Multi-cluster Management**: Unified control plane
- **Update Orchestration**: Coordinate upgrades across clusters
- **Workload Placement**: Deploy applications across cluster fleet
- **Hub-cluster Architecture**: Central management hub
- **Consistency Policies**: Enforce configuration across clusters
- **Cross-cluster Networking**: Service discovery and communication
- **Resource Optimization**: Balance load across fleet
- **Compliance & Governance**: Unified policy enforcement
