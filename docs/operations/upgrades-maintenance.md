# Upgrades & Maintenance

<span className="badge--intermediate">📚 Intermediate</span>

Learn to plan and execute AKS cluster upgrades safely. Understand auto-upgrade channels, planned maintenance windows, and node image updates.

## Key Concepts

- **Auto-Upgrade Channels**: Automatic Kubernetes version updates
- **Maintenance Windows**: Scheduled maintenance scheduling
- **Node Image Updates**: Security patches and OS updates
- **Control Plane Upgrades**: Kubernetes API server updates
- **Node Pool Upgrades**: Worker node orchestration
- **Surge Nodes**: Temporary capacity during upgrades
- **Downtime Prevention**: Rolling update strategies
- **Validation & Testing**: Pre-production upgrade verification
