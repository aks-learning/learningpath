# Horizontal Pod Autoscaler

<span className="badge--intermediate">📚 Intermediate</span>

Learn to configure Horizontal Pod Autoscaler (HPA) for automatic pod scaling based on resource metrics and custom metrics. Ensure optimal application performance during traffic spikes.

## Key Concepts

- **HPA Controller**: Kubernetes built-in autoscaling controller
- **Metrics-Based Scaling**: CPU and memory thresholds
- **Custom Metrics**: Scale based on application-specific metrics
- **Scaling Policies**: Control scaling speed and behavior
- **Target Utilization**: Define desired resource utilization levels
- **Cooldown Periods**: Prevent rapid scaling fluctuations
- **Scaling Limits**: Minimum and maximum replica counts
- **Metrics Server**: Metrics collection and aggregation
