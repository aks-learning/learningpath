# Inference Serving

<span className="badge--advanced">🚀 Advanced</span>

Learn to deploy and manage inference servers on AKS. Explore Triton Inference Server, Ray Serve, and other frameworks for production-grade model serving.

## Key Concepts

- **Triton Inference Server**: Multi-framework model serving
- **Ray Serve**: Scalable model serving framework
- **Model Formats**: ONNX, TensorFlow, PyTorch models
- **Batch Inference**: Process multiple requests efficiently
- **Real-time Inference**: Low-latency request handling
- **Model Versioning**: A/B testing and gradual rollout
- **Resource Management**: GPU and memory allocation
- **Monitoring & Logging**: Production observability
