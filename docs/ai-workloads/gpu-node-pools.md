# GPU Node Pools

<span className="badge--advanced">🚀 Advanced</span>

Learn to provision and manage GPU node pools in AKS for machine learning, AI inference, and compute-intensive workloads. Understand GPU scheduling and resource management.

## Key Concepts

- **NVIDIA GPU Support**: NVIDIA driver installation and management
- **Node Pool Configuration**: GPU VM sizes and skus
- **Device Plugins**: Kubernetes GPU resource exposure
- **Scheduling**: Pod GPU resource requests and limits
- **GPU Isolation**: Single and multi-GPU allocation
- **Power Management**: GPU power states and thermal management
- **Cost Optimization**: Right-sizing GPU resources
- **Monitoring**: GPU utilization and performance
