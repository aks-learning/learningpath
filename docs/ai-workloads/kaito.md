# KAITO (AI Toolchain Operator)

<span className="badge--advanced">🚀 Advanced</span> [<span className="badge--new">🆕 New</span>]

Master KAITO (Kubernetes AI Toolchain Operator) for automated AI model deployment. Simplify model serving and leverage pre-configured toolchains for popular AI frameworks.

## Key Concepts

- **Automated Model Deployment**: Simplified model serving setup
- **Supported Models**: Pre-configured popular LLMs and AI models
- **Resource Provisioning**: Automatic node pool scaling
- **Inference Optimization**: GPU memory and compute optimization
- **Multi-model Serving**: Run multiple models simultaneously
- **Workspace Management**: Persistent model environments
- **RAG Engines**: Retrieval-Augmented Generation support
- **Integration**: Works with AKS GPU node pools
