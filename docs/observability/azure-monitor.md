# Azure Monitor & Container Insights

<span className="badge--intermediate">📚 Intermediate</span>

Learn to monitor your AKS clusters and containerized applications using Azure Monitor and Container Insights. Collect metrics, logs, and performance data for operational insights.

## Key Concepts

- **Container Insights**: Azure Monitor solution for Kubernetes monitoring
- **Log Analytics**: Centralized logs collection and querying
- **Metrics**: Cluster, node, and pod performance metrics
- **Live Logs**: Real-time container log streaming
- **Performance Monitoring**: Resource utilization and bottleneck detection
- **Alerting**: Proactive notifications for issues
- **Cost Tracking**: Monitor spending on Container Insights
