# Managed Prometheus & Grafana

<span className="badge--intermediate">📚 Intermediate</span>

Explore Azure Managed Prometheus for scalable metrics collection and Azure Managed Grafana for visualization. Build custom dashboards and gain deep insights into your AKS workloads.

## Key Concepts

- **Azure Managed Prometheus**: Fully managed Prometheus service
- **Metrics Collection**: Scrape endpoints for custom metrics
- **PromQL**: Query language for Prometheus data
- **Azure Managed Grafana**: Visualization and dashboarding service
- **Custom Dashboards**: Build tailored monitoring views
- **Alerting Rules**: Define alert conditions and notifications
- **Multi-cluster Monitoring**: Unified view across clusters
- **Cost Optimization**: Pay per metrics ingested
