# Support & Version Policy

<span className="badge--beginner">🌱 Beginner</span>

Understand AKS support policies, Kubernetes release cycles, and version lifecycle management. Learn about Long-Term Support (LTS) versions and how to plan upgrades.

## Key Concepts

- **Kubernetes Version Support**: N-3 support window
- **LTS Releases**: Extended support versions
- **Release Cadence**: Regular feature and patch releases
- **Support Status**: Active, deprecated, and end-of-support
- **Upgrade Requirements**: Version compatibility constraints
- **Patch Releases**: Security and bug fix updates
- **Release Tracker**: Visibility into upcoming changes
- **Planning Cycles**: Align upgrades with business cycles
